# Mochi no Norte SI

Desenho e motor de animação originais do Coucou, por Louis-CFM / Louis Raillé, MIT. Origem: https://github.com/Louis-CFM/coucou — commit 16ae7b2b69d9db792f5a564e2cd3a803b3aa4bb4.

O motor Canvas 2D é usado sem ilha, janela ou fundo. engine.ts/outfits.ts/wardrobe.ts/anim.ts/layout.ts preservam o código original. sound.ts é um adaptador silencioso. native.ts integra os estados ao painel, pausa fora da tela e respeita movimento reduzido. O resultado compilado está em src/mochi-native.js e é incorporado ao HTML. Não há vídeos, downloads automáticos, galeria ou dependências externas em execução.
